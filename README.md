# NEXUS Calculator - Direct APK (No Laptop Build)

### HOW TO GET APK WITHOUT LAPTOP - 100% CLOUD:

1. Create free account on github.com (on your phone)
2. Create new repository -> Upload ALL files from this zip
3. Go to Actions tab -> You will see "Build NEXUS APK" running
4. After 3-4 minutes, click on the run -> Download artifact "NEXUS-Calculator-APK"
5. You get app-debug.apk - install on any Android phone

No Android Studio, no laptop, no command line needed!

### Even Faster (30 seconds, phone only):

1. Go to pwabuilder.com on your phone browser
2. Upload www/index.html to netlify.com (drag & drop) to get a link
3. Paste link in PWABuilder -> Android -> Generate APK
4. Direct APK download

You have futuristic calculator with 4 themes ready.
